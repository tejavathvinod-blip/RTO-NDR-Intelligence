# RTO-NDR-Intelligence

A Buyer Reliability Intelligence Framework for analyzing Return to Origin (RTO), Non-Delivery Reports (NDR), and customer ordering behavior.

## Project Contents

- Power BI dashboard
- Customer dataset
- Order dataset
- RTO analysis report
- Python-based RTO simulation
